# 数独成长学院（Sudoku Academy）

独立数独成长训练网页，面向7—28岁学习者，按年龄阶段逐步提高棋盘规模与逻辑要求。

## 当前版本
V0.1：4×4、6×6、9×9数独；自动生成唯一解题目；基础提示、候选数显示、计时、本地进度保存。

## GitHub Pages
仓库 Settings → Pages → Deploy from a branch，选择 `main` 和 `/ (root)`。

## 隐私
游戏进度仅保存在玩家当前浏览器 localStorage。

## 开发路线
后续将加入按解题技巧生成题目、逐步教学、错题复习、成就和每日挑战。年龄分级是学习路径，不代表严格难度认证。
